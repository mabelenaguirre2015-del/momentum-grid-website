# Momentum Grid landing page

A responsive static landing page built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure, copy, inline SVG logo, SEO metadata
- `style.css` — responsive styling and brand system
- `script.js` — mobile navigation, current year, and email-based contact form

## Before publishing
1. Open `script.js`.
2. Replace `YOUR_EMAIL@example.com` with the email address where you want to receive enquiries.
3. Review the copy and confirm the audit scope matches the service you intend to sell.
4. If you want a form that submits directly without opening the visitor's email app, connect a form service or backend. This starter version intentionally does not pretend to send form submissions to a server.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload all three files to the repository root (not inside an extra nested folder).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and the `/(root)` folder, then save.
6. Wait for GitHub Pages to publish the site and open the URL shown in the Pages settings.

## Connect your own domain
In **Settings → Pages → Custom domain**, enter the domain you own and save it. Follow the DNS records GitHub Pages displays for that domain at your domain registrar. Enable HTTPS in Pages after DNS is verified. DNS propagation can take some time.

## Notes
- The logo is an inline SVG included in the HTML; no separate logo file is required.
- Fonts load from Google Fonts. System fallbacks are included.
- The site does not include fake testimonials, fabricated metrics, or invented customer logos.
- Update the SEO description and social preview metadata if the positioning changes.
